1. CAPTURE (eyes) — vision model reads the raw image.
2. OVERLAY (Spatial Cognition Key) — place the tetractys (or pine-cone)
   glyph over the image: 1 singularity + radiating anchor points.
3. SOLOBRIZE — convert visual artifact → Drayl layers (meaning, not just shape).
4. JHANOS MAP — assign each region a Solobic coordinate
   (e.g. TARA-5, ORON-2) by vector + distance from center.
5. ARCHIVE — write a source-linked, hash-stamped Drayl layer.
