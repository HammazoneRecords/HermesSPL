# Solobility Output Format & Rules

## Return format
1. The requested tier(s) of the passage
2. A brief note on which concepts were shown versus named
3. Any claims that need external verification
4. Open questions the user should decide

## Verification rules
- The four gates, ninth Echo, Gene glue, and Turin checkpoint are the user's conceptual model, not established physics.
- Separate design intent from established fact in every specification.
- Do not expose personal credentials, phone numbers, or intellectual property.
