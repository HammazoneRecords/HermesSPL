## What Is It?

HermesSPL is a **public, installable fork of Hermes Agent** that adds:

- **450 formalized concepts** from the Book of Solobility as a shared operating philosophy
- **RITE cycle governance** — Resonance → Initiation → Trigger → Echo
- **Color Neutralizer** — pre-processing that scrubs false contrasts from tool inputs
- **Solobic CPU** — runtime arbitration of ROM/RAM/Drayl memory tiers
- **Shimmer Feedback Loop (SFL)** — ethical governance layer gating output by readiness
- **Signal Protocol** — 5-state output gating (000/001/010/100/111)
- **Drayl Backend** — active source-linked archive, not passive storage
- **Session Access Guard** — granular policy enforcement for session access
- **Multi-chat desktop** — hold multiple conversations, each with its own agent
- **Jamaica RBG theme** — Red-Black-Green Rastafarian palette, dark and light variants

## Install

### Windows (PowerShell)

```powershell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
```

Then clone or download this fork, and run:

```powershell
.\triangulum init
.\triangulum run
```

### Linux / macOS / WSL2

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

Then:

```bash
./triangulum init
./triangulum run
```
